Set a new password

Give the address the account is on, and a link to set a new password goes to it. The link works once, and it does not stay good for long.

The answer is the same whether or not there is an account on that address — otherwise this page would be a way for a stranger to find out who has one.

Choose a new one. At least 10 characters. Length is what makes a password hard to guess; a short one with a symbol in it is still short.

Setting a new password signs out every machine that was already signed in to this account. If somebody else got in, this is what puts them out.

Done. The password is changed and you are signed in on this machine. Every other machine that was signed in has been signed out.
