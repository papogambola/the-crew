The Crew · recovery

Get a lost game back

Builds before 98 served the game on a different port every time they started. The browser inside the app files saved games under the address they were saved at — so each launch looked in a new, empty drawer and offered you a new game. Nothing was deleted. The old games are still on your disk, in drawers the app stopped opening.

If you are on build 97 or earlier, stop playing it. Every launch strands the game before it. Build 98 is the first one that keeps a save — get it from the front page, and unzip it over the copy you have rather than into a new folder, so it inherits the same storage and everything below still applies.

1 · Close the game

All of it — the window, and any copy still running. The files are locked while it is open.

2 · Find where the game lives

Press Win, type The Crew, right-click the result and choose Open file location. That is the folder — most likely inside Downloads, wherever you unzipped it. You are looking for The Crew.exe.

In that folder, beside The Crew.exe, resources.neu and READ ME, there will be a folder called .tmp. That is the one. You can tell it apart from the rest by its date: the other three are from when you unzipped the game, and .tmp is from the first time you ran it — the app made it, and the browser inside the app keeps its storage there.

If you cannot see it, it is hidden: in File Explorer, View → Show → Hidden items.

A folder called The Crew.exe.WebView2 beside the exe is the other place this can land, and it was the only one this page named at first — wrongly, for the build Paz had. If you have that one instead, it works the same way. Either way what you are hunting for inside is a folder called leveldb, holding files that end .ldb and .log.

3 · Or just ask the computer where it is

Press Win+R, type powershell, press Enter, paste this one line, press Enter. It only looks and prints — it changes nothing, creates nothing, and deletes nothing. Give it a few minutes.

Get-ChildItem $env:USERPROFILE -Recurse -Force -ErrorAction SilentlyContinue | Where-Object { $_.Name -eq 'The Crew.exe' -or $_.Name -eq 'leveldb' } | ForEach-Object { $_.FullName }

Every line it prints ending in leveldb is a folder that may hold a saved game. Every line ending in The Crew.exe is a copy of the game. If it prints nothing at all, say so — that is information too, and it rules out the whole of your user folder in one go.

4 · Copy that whole folder to your Desktop. Now, before anything else.

Right-click .tmp (or The Crew.exe.WebView2, whichever you have), Copy, then paste it on your Desktop. This is the step that actually saves you: everything below can be retried as often as you like once you have a copy, and nothing below can hurt a copy that is already made.

Do this before you uninstall, delete or move anything. Deleting the game folder deletes this with it, and that is the only copy there is.

Chromium reclaims storage for addresses nothing visits any more. Your old games are at addresses nothing will ever visit again, so they are exactly the kind it eventually clears. A copy on the Desktop is outside all of that.

5 · Or let the computer gather them

Press Win+R, type powershell, press Enter. Then select all of this, copy it, right-click in the PowerShell window to paste, and press Enter. It only reads and copies. Searching your whole user folder can take a couple of minutes.

$dst = Join-Path ([Environment]::GetFolderPath('Desktop')) 'crew-save-files'
New-Item $dst -ItemType Directory -Force | Out-Null
Write-Host "Searching $env:USERPROFILE - this can take a few minutes..."
$dirs = @(Get-ChildItem $env:USERPROFILE -Recurse -Force -Directory -Filter 'leveldb' -ErrorAction SilentlyContinue)
Write-Host "Found $($dirs.Count) leveldb folder(s):"
$n = 0
foreach ($d in $dirs) {
  Write-Host "   $($d.FullName)"
  $tag = ($d.FullName -replace '[^A-Za-z0-9]','_')
  if ($tag.Length -gt 50) { $tag = $tag.Substring($tag.Length - 50) }
  Get-ChildItem $d.FullName -Force -File -ErrorAction SilentlyContinue |
    Where-Object { $_.Extension -eq '.ldb' -or $_.Extension -eq '.log' } |
    ForEach-Object { Copy-Item $_.FullName (Join-Path $dst ($tag + '__' + $_.Name)) -Force; $n++ }
}
Write-Host "Copied $n file(s) to $dst"
Start-Process $dst

It prints every folder it found and how many files it copied, so it says something useful even when it finds nothing. If the count is 0, send me those printed lines — that tells me where to look next, which is better than me guessing at another path.

The Desktop path is read from Windows itself rather than assumed, because OneDrive moves the Desktop and an earlier version of this wrote to a folder that was not there.

7 · Put it back

  1. Open The Crew (build 98 or later — older builds will lose it again).
  2. Press Esc to open the office.
  3. Click the filing cabinet under the desk, on the right.
  4. Paste the code into the box and confirm. The game should name the commander and the week before you commit to it — check it is the one you want.

Recover your best game first and play it a little, so it is saved again under the new fixed address. Importing a second game overwrites the first.
